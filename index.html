Painel do Residencial Vila das Palmeiras

Roteiro completo para montar as 3 telas (Moradores, Movimento & Garagem, Ocorrências) a partir da planilha Base_PowerBI_Condominio.xlsx, com menu superior retrátil. Marque cada etapa ao terminar.

0 de 12 etapas
Etapas
    01

    Importar os dados

    1. Abra o Power BI Desktop e salve o projeto vazio como Painel_Condominio.pbix.
    2. Página Inicial › Obter dados › Pasta de Trabalho do Excel e escolha Base_PowerBI_Condominio.xlsx.
    3. No Navegador, marque as tabelas (ícone de tabela, não o de planilha): dUnidades, fMoradores, fMovimentacao, fOcupacaoEstac, dVagas, fOcorrencias, dCalendario, dHora. Ignore as abas LEIA-ME, Medidas_DAX, Layout_Telas e Menu_Retratil.
    4. Clique em Transformar Dados (não em Carregar) para conferir os tipos antes.
    Por que tabelas?Cada aba já está formatada como Tabela do Excel. Se um dia você acrescentar linhas na planilha, basta clicar em Atualizar no Power BI.
    02

    Ajustes no modelo

    1. Clique com o botão direito em dCalendario › Marcar como tabela de datas e escolha a coluna Data.
    2. Na exibição de tabela, selecione dCalendario[Mes_Nome] › Ferramentas de coluna › Classificar por coluna › Mes_Num. Repita para Mes_Abrev.
    3. Faça o mesmo com Dia_Semana classificado por Dia_Semana_Num, e Hora_Label por Hora_Cheia.
    4. Oculte (ícone de olho) as colunas Torre e Andar das tabelas f: nos visuais use sempre dUnidades[Torre] e dUnidades[Andar], assim um único filtro funciona nas 3 telas.
    Regra de ouroFiltros e eixos vêm das tabelas d (dimensões). Valores vêm das medidas.
    04

    Criar a tabela de medidas

    1. Página Inicial › Inserir dados, nomeie a tabela como _Medidas e clique em Carregar.
    2. Com a tabela _Medidas selecionada, use Nova medida e cole uma medida por vez.
    3. Quando tiver a primeira medida, apague a Coluna1. A tabela vira uma pasta de medidas e sobe para o topo da lista de campos.
    4. Ajuste o formato de cada medida em Ferramentas de medida (%, R$, casas decimais).

    Tela 1 · Moradores

    Total Moradores = COUNTROWS(fMoradores)

Total Unidades = COUNTROWS(dUnidades)

Unidades Ocupadas = CALCULATE([Total Unidades], dUnidades[Situacao] = "Ocupado")

Taxa de Ocupação = DIVIDE([Unidades Ocupadas], [Total Unidades])

Média Moradores por Ap = DIVIDE([Total Moradores], [Unidades Ocupadas])

Idade Média = AVERAGE(fMoradores[Idade])

Total Pets = SUM(dUnidades[Qtd_Pets])

% Inquilinos = DIVIDE(CALCULATE([Total Unidades], dUnidades[Tipo_Ocupacao] = "Inquilino"), [Unidades Ocupadas])

    Tela 2 · Movimento & Garagem

    Total Movimentos = COUNTROWS(fMovimentacao)

Entradas = CALCULATE([Total Movimentos], fMovimentacao[Tipo_Movimento] = "Entrada")

Saídas = CALCULATE([Total Movimentos], fMovimentacao[Tipo_Movimento] = "Saída")

Visitantes = CALCULATE([Entradas], fMovimentacao[Tipo_Pessoa] = "Visitante")

Média Movimentos por Dia = DIVIDE([Total Movimentos], DISTINCTCOUNT(fMovimentacao[Data]))

Permanência Média (min) = AVERAGE(fMovimentacao[Permanencia_min])

% Ocupação Estacionamento = DIVIDE(SUM(fOcupacaoEstac[Vagas_Ocupadas]), SUM(fOcupacaoEstac[Vagas_Total]))

Pico de Ocupação = MAX(fOcupacaoEstac[Vagas_Ocupadas])

    Tela 3 · Ocorrências

    Total Ocorrências = COUNTROWS(fOcorrencias)

Ocorrências Abertas = CALCULATE([Total Ocorrências], fOcorrencias[Status] <> "Resolvida")

% Resolvidas = DIVIDE(CALCULATE([Total Ocorrências], fOcorrencias[Status] = "Resolvida"), [Total Ocorrências])

Total Multas (R$) = SUM(fOcorrencias[Valor_Multa])

Tempo Médio Resolução (dias) = AVERAGE(fOcorrencias[Dias_Resolucao])

% Reincidência = DIVIDE(CALCULATE([Total Ocorrências], fOcorrencias[Reincidente] = "Sim"), [Total Ocorrências])

Ocorrências Fora do Horário = CALCULATE([Total Ocorrências], dHora[Horario_Silencio] = "Sim")

Cor Horário = IF(MAX(dHora[Horario_Silencio]) = "Sim", "#C2453A", "#5B7FA6")
    DicaCrie uma medida por vez. Se colar o bloco todo de uma vez, o Power BI dá erro: ele só aceita uma medida por fórmula.

    Montar a faixa superior e os filtros (Tela 1)

    2. Inserir › Formas › Retângulo na posição da faixa superior, cor #0F5257, sem borda.

    10

    Menu superior retrátil

    A ideia: um grupo grpMenu (painel com os botões de navegação) e um grupo grpFiltros (as segmentações). Dois indicadores por página alternam qual dos dois aparece.

    Montar o menu (na página Moradores)

    1. Desenhe um retângulo na mesma posição da faixa de filtros, mas um pouco mais alto (y 60, altura 110), na cor da faixa superior.
    2. Dentro dele, insira 3 botões Em branco com os textos Moradores, Movimento & Garagem e Ocorrências.
    3. Em cada botão: Ação › Tipo: Navegação de página › Destino a página correspondente.
    4. Insira um botão ✕ no mesmo lugar do ☰ e nomeie btnFechar.
    5. No painel Seleção, selecione o retângulo, os 3 botões e o btnFechar › botão direito › Agrupar. Renomeie o grupo para grpMenu.
    6. Selecione todas as segmentações › Agrupar › renomeie para grpFiltros.

    Criar os indicadores

    1. Exibir › Indicadores para abrir o painel.
    2. Estado fechado: no painel Seleção, oculte grpMenu (olho) e deixe grpFiltros e btnAbrir visíveis. Clique em Adicionar e renomeie para P1 Menu Fechado.
    3. Estado aberto: mostre grpMenu, oculte grpFiltros e btnAbrir. Adicione e renomeie para P1 Menu Aberto.
    4. Em cada um dos dois indicadores, clique em … e desmarque "Dados". Deixe marcados "Exibir" e "Página atual".
    5. Volte ao estado fechado clicando no indicador P1 Menu Fechado.
    Não puleCom "Dados" marcado, o indicador grava os filtros do momento. Cada vez que o usuário abrir o menu, os filtros dele seriam apagados.

    Ligar os botões

    1. btnAbrir (☰) › Ação › Tipo: Indicador › P1 Menu Aberto.
    2. btnFechar (✕) › Ação › Tipo: Indicador › P1 Menu Fechado.
    3. Teste com Ctrl + clique no Desktop.

    Repetir nas outras páginas

    1. Copie grpMenu e btnAbrir da página Moradores (Ctrl+C) e cole nas outras (Ctrl+V). O Power BI pergunta se quer sincronizar: escolha Sincronizar, assim os objetos ficam na mesma posição.
    2. Agrupe as segmentações de cada página como grpFiltros.
    3. Crie os indicadores P2 Menu Fechado / P2 Menu Aberto e P3 Menu Fechado / P3 Menu Aberto, sempre com "Dados" desmarcado, e ligue os botões ☰ e ✕ de cada página aos indicadores da própria página.
    4. Opcional: nos botões de navegação, use Ação › Indicador › P2 Menu Fechado em vez de Navegação de página. Assim o usuário chega na outra tela já com o menu recolhido.
    11

    Sincronizar filtros entre telas

    1. Exibir › Sincronizar segmentações.
    2. Selecione a segmentação de Torre e marque as 3 páginas nas duas colunas (sincronizar e visível).
    3. Faça o mesmo com Mês nas páginas Movimento e Ocorrências.

    Agora, ao escolher Torre A na tela de moradores e navegar pelo menu, as outras telas já abrem filtradas.

    12

    Acabamento e entrega

    1. Dê títulos claros a todos os visuais (nada de "Contagem de ID por Andar").
    2. Na lista de campos, oculte as colunas das tabelas f que já viraram medidas (IDs, Valor_Multa, Vagas_Ocupadas). Fica mais fácil achar o que importa.
    3. Oculte o painel lateral de filtros para o usuário final (Formatar › Painel de filtros › Visibilidade). Os filtros dele são as segmentações.
    4. Teste o clique cruzado: clicar numa barra de "Por categoria" deve filtrar o restante da tela 3.
    5. Publique em Página Inicial › Publicar. No serviço, os botões funcionam com clique simples.
